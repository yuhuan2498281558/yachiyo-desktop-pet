# 八千代与辉夜桌宠

一个面向 Windows 的透明双形态桌宠。角色素材依据用户提供的《超时空辉夜姬！》原片参考帧重新绘制；“星降之海”使用用户提供的场景插画，并叠加独立鱼群与角色动画，仅用于本地个人展示。

![八千代桌宠预览](assets/preview.png)

## 功能

- 八千代与辉夜双形态，以及连接式变身动画。
- 八千代可使用 GitHub 原版 Live2D 模型；Live2D 固定待机，手动拖动时冻结姿势并平移，松手后恢复。随机散步仅作用于 Sprite 形象；右键菜单可随时切回经典 Sprite，模型缺失、WebGL 加载失败、变身和演唱会期间会安全回退。
- 自动读取本机 Codex 任务记录：任务开始后切换为辉夜，收到 `task_complete` 或 `turn_aborted` 后才恢复八千代。
- 全局鼠标视线追随：鼠标不在桌宠窗口内也能生效；八千代使用 16 方位专用帧，辉夜使用轻微朝向补偿。
- 托盘菜单可选择自动形态、锁定八千代或锁定辉夜。
- 透明无边框、始终置顶、不占任务栏，支持拖动、点击互动和双击跳跃。
- 可选随机散步、鼠标穿透、三档尺寸，并自动保存位置和偏好。
- 偏好经过类型校验并原子保存，退出前刷新最后一次修改；拖动优先于散步与形态转换。
- Codex 状态扫描在独立工作线程运行，未变化的会话复用解析缓存。
- “星降之海”演唱会场景：星空鸟居、樱花水面与水晶阶梯背景，远近两层发光鲸鱼/鳐鱼群、角色倒影及逐阶涟漪；八千代撑红伞完成多段下阶演出。
- 98 句原创情境台词：区分八千代与辉夜的人设，并覆盖等待、工作、跳跃、成功、失败、身份转换和演唱会互动，最近三句不会重复。
- 单实例运行；重复启动会召回已经运行的桌宠。

## 本地运行

需要 Node.js 20 或更高版本。

```powershell
npm install
npm start
```

## 打包

生成适合从固定目录运行的解包版：

```powershell
npm run build
```

生成可选择安装目录的 NSIS 安装包：

```powershell
npm run dist
```

仅在明确需要单文件分发时生成 portable 包：

```powershell
npm run build:portable
```

portable 包运行时会解压到 Windows 临时目录，不适合作为日常启动入口。

输出文件位于 `release/`。

## 操作

- 左键单击：互动并随机说一句话。
- 左键双击：跳一下。
- 按住左键拖动：移动桌宠。
- 右键：打开桌宠菜单。
- 系统托盘右键：切换形态、视线追随、散步、穿透、尺寸和演唱会场景。
- 桌宠或托盘右键 → “八千代形象”：在“Live2D（GitHub 原版）”与“经典 Sprite（兼容模式）”之间切换；选择会自动保存。
- “Live2D 画质”：标准最高 60 FPS、按屏幕比例渲染（最高 2×）；省电最高 30 FPS、最高 1× 渲染。即时切换无需重载模型；省电档在高 DPI 屏幕上更柔和，原始贴图不变，不承诺降低纹理内存。
- “Live2D 视线风格”：柔和转头或仅眼睛跟随；两档均平滑追随，关闭“全局视线追随”后回正。单击轮换微笑、害羞与大笑，连续点击有冷却，双击仍可跳跃。隐藏桌宠会暂停 Live2D 渲染。
- “关于与诊断”：查看版本及模型状态、打开当前程序或日志文件夹。
- 菜单“场景 → 星降之海”：进入演唱会；选择“重播踩阶梯”可再次播放；选择“关闭场景”恢复普通桌宠。
- 开启鼠标穿透后，从系统托盘菜单关闭穿透。
- 本地诊断日志位于用户数据目录的 `logs/diagnostics.jsonl`；最多保留当前及上一份各 256 KiB，仅记录运行状态与错误码。

## Codex 状态识别

自动模式只读取本机 `.codex/sessions` 里的任务事件，不读取或上传对话正文。它以任务生命周期事件为准，不使用短时静默超时，所以长时间推理、生成图片或执行命令时会继续保持辉夜形态。

如果任务被外部强制终止而没有写入结束事件，可从托盘菜单选择“锁定八千代”；重新选择“自动：工作时辉夜”即可恢复自动模式。

## 回归验证

`npm test` 和 `npm run check` 验证逻辑与语法；`npm run test:electron` 使用独立临时偏好启动真实 Electron，测试拖动、形态/场景切换、退出保存及重启，不修改日常偏好。需要本地 Live2D 模型。长测可追加 `-- --soak-minutes 30`；打包版可追加 `-- --exe "完整 exe 路径"`。

`npm run benchmark:activity` 测量本机扫描缓存及主线程响应，不输出会话正文或会话路径。
